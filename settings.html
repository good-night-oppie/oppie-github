导入 App 私钥

私钥直接交给 Cindy 保险库，只在导入这一步注入插件后台；后台先向 GitHub 核对 App，再用本机 DPAPI 加密保存。导入结束后保险库里的副本会被清除。不要把私钥发给任何人。

导入前会先用这把私钥向 GitHub 读出 App 的安装、权限和仓库，显示在确认框上；确认后才保存。
